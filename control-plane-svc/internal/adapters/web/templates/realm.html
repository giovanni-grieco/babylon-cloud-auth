Create users

Every row is checked first. If any row is wrong, nothing is created. Each new user gets a temporary password, which is shown once and must be changed at first sign-in.

File format

CSV, with a header row. Separate groups with ;.

username,email,groups
mrossi,mrossi@{{with .Info.Domains}}{{index . 0}}{{else}}example.test{{end}},service-a;service-b

JSON:

{"users": [
  {"username": "mrossi", "email": "mrossi@{{with .Info.Domains}}{{index . 0}}{{else}}example.test{{end}}", "groups": ["service-a"]}
]}

The email is required and must use one of the domains above: the central Keycloak picks the realm from it at sign-in. Usernames can't contain @.
